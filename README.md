# TaskMate

TaskMate is a PHP and MySQL-based task and service marketplace.

## Features

- User registration and login
- Role-based customer, helper, and admin access
- Task posting and browsing
- Helper offers and offer management
- Customer-helper chat
- Task progress and completion workflow
- User profiles and reviews

## Technology Stack

- PHP
- MySQL
- HTML, CSS, and JavaScript
- Composer

## Setup

1. Install XAMPP and Composer.
2. Clone or download this repository.
3. Install dependencies with `composer install`.
4. Configure the database connection locally.
5. Import the required database schema.
6. Start Apache and MySQL, then open the project in your local environment.

## Note

Configure database credentials and email settings locally. Never commit passwords, app passwords, or other secrets.
